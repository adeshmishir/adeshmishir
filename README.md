### 🤖 CodePilot AI

An AI-powered developer assistant that analyzes GitHub repositories and provides contextual assistance for understanding and improving code.

**Features:**

* Repository parsing and code indexing
* RAG-based code question answering
* AI agents for planning, fixing, refactoring, testing, and PR reviews
* Semantic code search
* GitHub repository integration

**Tech:** React, Vite, FastAPI, PostgreSQL, Qdrant, embeddings, GitPython, Tree-sitter, Groq

🔗 [GitHub Repository](https://github.com/adeshmishir/CodePilot-AI)

---

### ⚙️ JobQueue

A distributed asynchronous task-processing system designed around reliable job execution and worker-based processing.

**Features:**

* Redis-backed job queue
* Multiple workers for parallel processing
* Automatic retries
* Dead Letter Queue for failed jobs
* Persistent job states
* Dockerized services
* PostgreSQL-based job tracking

**Tech:** React, Express.js, BullMQ, Redis, PostgreSQL, Docker

🔗 [GitHub Repository](https://github.com/adeshmishir/jobQueue)

---
